# STEAL YOUR VOICE

Панель управления **Voicemeeter** в стиле **Persona 5 Royal**: красный, чёрный, рваные плашки и заголовки в духе визитки Призрачных воров.

Voicemeeter висит в трее и делает всю работу со звуком, а Steal Your Voice даёт нормальный интерфейс для главного: микрофона и того, что уходит в запись.

## Что умеет

- **Микрофон** (любой Hardware Input): громкость, шумодав (Gate), компрессор, тембр, MONO, MUTE, «слышать себя» (A1), «в запись» (B1).
- **Выбор устройства** входа прямо из панели (WDM/MME).
- **Индикаторы уровня** микрофона и выхода B1: сразу видно, пишется голос или нет.
- **Выход B1** (то, что слышат ShadowPlay, Discord и OBS): громкость и mute.
- **Пресеты**: ЧИСТЫЙ / СТРИМ / СЫРОЙ и **свои**: «+ СВОЙ» сохраняет текущие настройки, ПКМ по пресету перезаписывает или удаляет его.
- **Горячая клавиша mute микрофона** (по умолчанию Pause, работает из любой игры) с плашкой «MIC OFF / MIC ON» поверх экрана.
- **Автонастройка**: 3 секунды тишины и 5 секунд голоса, после чего программа сама выставит громкость, шумодав, компрессор и MONO, а заодно подскажет, крутить ли GAIN на интерфейсе.
- **Диагностика**: маршрутизация Voicemeeter, сигнал (нет голоса, перегруз, один канал), частота 48 кГц у всех устройств, доступ к микрофону и приглушение звука Windows. Большинство проблем исправляется одной кнопкой.
- **Автоприглушение**: пока ты говоришь, звук игры или музыки на виртуальных входах Voicemeeter (VM Input / AUX) становится тише на заданное число dB, а потом плавно возвращается. Кнопка «ИГРА → КЛИПЫ (B2)» собирает игру и голос в шину B2 для ShadowPlay, а в Discord (B1) остаётся только голос.
- **Анимации в стиле меню P5**: красно-чёрный росчерк через весь экран, буквы заголовка «шлёпаются» по одной, карточки влетают с боков, окна выпрыгивают, экран трясётся при переключении mute.
- **Звуки интерфейса**: свои, синтезированные в коде. Их можно заменить своими .wav (`hover`, `click`, `confirm`, `cancel`, `whoosh`) в `%AppData%\StealYourVoice\sounds\`.
- **Discord отдельно**: громкость друзей (вход AUX) своим ползунком и режим «игра тише под друзей».
- **Индикатор поверх игры**: маленькая полоска уровня микрофона и плашка MIC OFF в выбранном углу экрана, клики проходят сквозь неё.
- **Пресеты по играм**: свой пресет можно привязать к игре, он включится при её запуске, а после выхода вернутся прежние настройки.
- **Громкость каждого друга отдельно**: кнопка «ДРУЗЬЯ» показывает людей в голосовом канале Discord с ползунком 0–200% и mute на каждого. Работает через локальный RPC Discord: нужно один раз создать своё приложение на Discord Developer Portal и вставить его Client ID и Secret (хранятся зашифрованными).
- **Исключения для автоприглушения**: можно отметить программы, которые не глушатся (например, музыку). Тогда приглушение идёт по программам через микшер Windows.
- **Автозапуск** вместе с Windows сразу в трей.
- **Перезапуск аудиодвижка** и открытие Voicemeeter одной кнопкой.
- **Трей**: «—» прячет окно, из меню иконки можно включить или выключить микрофон.
- Если Voicemeeter не запущен, панель предложит его запустить.
- **Автообновление**: при запуске, каждые 30 минут и при открытии окна из трея проверяет релизы на GitHub, сама скачивает новую версию, после чего достаточно нажать «ОБНОВИТЬ».

Работает с Voicemeeter Standard, Banana и Potato. Лучше всего с **Banana**.

## Установка

1. Установи [Voicemeeter Banana](https://vb-audio.com/Voicemeeter/banana.htm).
2. Скачай `StealYourVoice.exe` из [Releases](../../releases) и запусти. Устанавливать ничего не нужно.

Запуск свёрнутым в трей: `StealYourVoice.exe --tray`.

## Сборка

```
dotnet publish src/StealYourVoice -c Release -r win-x64 --self-contained -p:PublishSingleFile=true
```

Нужен .NET 8 SDK. Каждый пуш в `main` автоматически выпускает релиз для версии из `<Version>` в .csproj: чтобы выпустить новую, просто подними версию.
